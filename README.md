# Publish Project

This [Website](https://qaisstory.vercel.app/) was published to help my English teacher in his stories.

## Get Started

In the project directory, you can run:

### `npm start`

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

The page will reload when you make changes.\
You may also see any lint errors in the console.

## Change Story

In *./src/json/story.json* it has a file where you can edit and it will change all parameters of story.

You can change:
- Step
- Options
- Consequences

### Step
Steps is a part of the story that you can occur.

### Options
"Options" are the choices available to the player for each step.

### Consequences
Each "option" has consequences that should be determined by a dice.
